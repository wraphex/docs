# Android 系统应用恢复指南：从反射到原生实现

## 前言

许多现代 Android 系统允许用户卸载部分非核心的“可卸载系统应用”以减少资源占用或简化界面，然而当用户误删关键组件或需要恢复特定功能时，如何优雅地复原这些应用？下面进行介绍。

## 添加权限

```Java
<uses-permission android:name="android.permission.INSTALL_PACKAGES" />
<uses-permission android:name="com.android.permission.INSTALL_EXISTING_PACKAGES" />
```

|实现方式|PackageInstaller#installExistingPackage|PackageManager#installExistingPackage|
|---|---|---|
|调用|packageManager.getPackageInstaller()|packageManager反射|
|优点|不需要反射，利用IntentSender跳转|兼容低版本API level|
|缺点|需要Android API level >= 29|需要反射 需要监听安装广播实现跳转|
|需要系统签名|是|是|

## 新的实现方式(Android API level >= 29)

### PackageInstaller#installExistingPackage

可以不用设置安装完成广播监听，使用IntentSender进行跳转

### 源码

```Java

/**
 * Install the given package, which already exists on the device, for the user for which this
 * installer was created.
 *
 * <p>This will
 * {@link PackageInstaller.SessionParams#setWhitelistedRestrictedPermissions(Set) allowlist
 * all restricted permissions}.
 *
 * @param packageName The package to install.
 * @param installReason Reason for install.
 * @param statusReceiver Where to deliver the result of the operation indicated by the extra
 *                       {@link #EXTRA_STATUS}. Refer to the individual status codes
 *                       on how to handle them.
 */
@RequiresPermission(allOf = {
        Manifest.permission.INSTALL_PACKAGES,
        Manifest.permission.INSTALL_EXISTING_PACKAGES})
public void installExistingPackage(@NonNull String packageName,
        @InstallReason int installReason,
        @Nullable IntentSender statusReceiver) {
    Objects.requireNonNull(packageName, "packageName cannot be null");
    try {
        mInstaller.installExistingPackage(packageName,
                PackageManager.INSTALL_ALL_WHITELIST_RESTRICTED_PERMISSIONS, installReason,
                statusReceiver, mUserId, null);
    } catch (RemoteException e) {
        throw e.rethrowFromSystemServer();
    }
}
```

### 调用

```Java
PackageInstaller packageInstaller = pm.getPackageInstaller();
packageInstaller.installExistingPackage(packageName, PackageManager.INSTALL_REASON_USER, statusReceiver);
```

## 过期的实现方式

### PackageManager#installExistingPackage

#### 源码

```Java
/**
 * If there is already an application with the given package name installed
 * on the system for other users, also install it for the calling user.
 * @hide
 *
 * @deprecated use {@link PackageInstaller#installExistingPackage()} instead.
 */
@SuppressWarnings("HiddenAbstractMethod")
@Deprecated
@SystemApi
public abstract int installExistingPackage(@NonNull String packageName)
        throws NameNotFoundException;
```

#### 反射调用

```Java
public static boolean recallSystemApp(PackageManager pm, String packageName) {
    int code = (int) MzReflectHelper.invokeMethodWithReturn(pm, "installExistingPackage", new Class[]{String.class}, new Object[]{packageName});
    int succeededCode = (int) MzReflectHelper.getStaticField("android.content.pm.PackageManager", "INSTALL_SUCCEEDED");
    return code == succeededCode;
}
```

## 完整实例

```Java

private static void tryStartActivity(Context context, Intent intent) {
    if (context == null || intent == null) return;
    intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
    try {
        context.startActivity(intent);
    } catch (ActivityNotFoundException e) {
        View view = LayoutInflater.from(context).inflate(R.layout.layout_install_popup, null, false);
        new AlertDialog.Builder(context)
                .setView(view)
                .setPositiveButton(R.string.install, (dialog, whichButton) -> {
                    PendingIntent pendingIntent = PendingIntent.getActivity(context, 0, intent, PendingIntent.FLAG_UPDATE_CURRENT | PendingIntent.FLAG_IMMUTABLE);
                    IntentSender statusReceiver = pendingIntent.getIntentSender();
                    recallSystemApp(context.getPackageManager(), intent.getPackage(), statusReceiver);
                })
                .setNegativeButton(R.string.cancel, (dialog, whichButton) -> {
                })
                .show();
    }
}

public static void recallSystemApp(PackageManager pm, String packageName, IntentSender statusReceiver) {
    Timber.d("recalling %s", packageName);
    PackageInstaller packageInstaller = pm.getPackageInstaller();
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
        packageInstaller.installExistingPackage(packageName, PackageManager.INSTALL_REASON_USER, statusReceiver);
    } else {
        ReflectHelper.invokeMethodWithReturn(pm, "installExistingPackage", new Class[]{String.class}, new Object[]{packageName});
        ReflectHelper.getStaticField("android.content.pm.PackageManager", "INSTALL_SUCCEEDED");
    }
}
```
