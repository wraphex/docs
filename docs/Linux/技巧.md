# 技巧

## ssh密钥登录

[https://wiki.archlinuxcn.org/wiki/SSH_密钥](https://wiki.archlinuxcn.org/wiki/SSH_%E5%AF%86%E9%92%A5)

```bash
ssh-keygen
ssh-copy-id ip/域名
```

## FTP

[https://wiki.archlinuxcn.org/wiki/Very_Secure_FTP_Daemon](https://wiki.archlinuxcn.org/wiki/Very_Secure_FTP_Daemon)

```bash
paru -S vsftpd
sudo systemctl restart vsftpd.service
```

### 启用root登录

/etc/ftpusers 注释root

```bash
sudo systemctl restart vsftpd.service
```

## 蓝牙

[https://wiki.archlinux.org.cn/title/Bluetooth](https://wiki.archlinux.org.cn/title/Bluetooth)

## NTP时间同步

查看timedatectl status

```bash
timedatectl status
```

开启同步

```bash
timedatectl set-ntp true
```

## 删除多余bios启动项

```bash
paru -S efibootmgr
```

列出系统中所有的 UEFI 启动项：

```bash
sudo efibootmgr
```

根据编号删除不需要的启动项

```bash
sudo efibootmgr -b xxxx -B
```

- *b* 指定要删除的启动项编号。
- *B* 表示删除该启动项。
