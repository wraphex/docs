# 用户级服务开机自启动解决方案

## 使用 Lingering

通过 `loginctl enable-linger` 命令，可以确保指定用户的用户级 systemd 实例在系统启动时自动运行，从而使其管理的服务能够开机自启，无需登录。

1. 为当前用户启用 Lingering
    
    ```bash
    loginctl enable-linger $USER
    ```
    
	这个命令会为你的用户创建一个标记，告诉系统在启动时就需要初始化该用户的 systemd 实例。
	
2. 验证状态
    
    你可以通过以下命令查看 Lingering 是否已成功启用：
    
    ```bash
    loginctl show-user $USER
    ```
    
    如果输出中包含 `Linger=yes`，即表示设置成功。
    

完成此操作后，使用 `systemctl --user enable` 启用的服务就会在下次系统重启时自动启动。
