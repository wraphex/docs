## Pascal及以下nvidia显卡安装显卡驱动

显卡代号查询 [https://nouveau.freedesktop.org/CodeNames.html](https://nouveau.freedesktop.org/CodeNames.html)

NVIDIA 590版本开源驱动已经放弃了Pascal及以下nvidia显卡的支持，nvidia包已替换为nvidia-open

[https://archlinux.org/news/nvidia-590-driver-drops-pascal-support-main-packages-switch-to-open-kernel-modules/](https://archlinux.org/news/nvidia-590-driver-drops-pascal-support-main-packages-switch-to-open-kernel-modules/)

nvidia-open驱动不支持Pascal及以下nvidia显卡，需要转为安装nvidia-580xx-dkms(AUR)

[https://wiki.archlinux.org/title/NVIDIA#Installation](https://wiki.archlinux.org/title/NVIDIA#Installation)

```bash
paru -S linux-headers nvidia-580xx-dkms nvidia-580xx-utils
```

禁用/etc/mkinitcpio.conf kms
