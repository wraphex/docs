# Docker网段

## 修改容器地址池

/etc/docker/daemon.json

```bash
{
  "default-address-pools": [
    {
      "base": "192.168.0.0/16",
      "size": 24
    }
  ],
  ...
}

```

这表示：

- Docker可以使用 `192.168.0.0/16` 这个大网段
- 每个自定义网络会分配一个 `/24` 的子网
- 自动分配的子网可能是：`192.168.1.0/24`、`192.168.2.0/24`、`192.168.3.0/24` 等
