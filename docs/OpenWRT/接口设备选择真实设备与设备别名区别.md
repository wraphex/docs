# OpenWRT - 接口设备选择真实设备与设备别名区别

在OpenWrt中添加新接口时，选择真实设备（如`eth1`）和设备别名（如`@eth1`）的区别：

## 1. 真实设备 (eth1)

- **直接绑定物理网卡**：创建的接口直接对应物理网络设备
    
- **独占控制**：该接口将完全控制这个物理设备
    
- **只能有一个**：同一个物理设备只能被一个接口直接使用
    
- **会覆盖原有配置**：如果eth1已被其他接口使用，新配置会替代原有配置
    

## 2. 设备别名 (@eth1)

- **虚拟接口**：在物理设备上创建的虚拟接口
    
- **共享物理设备**：允许多个别名接口共享同一个物理设备
    
- **多IP支持**：可以在同一物理设备上配置多个IP地址/子网
    
- **灵活管理**：每个别名接口可以有不同的防火墙区域、路由规则等
