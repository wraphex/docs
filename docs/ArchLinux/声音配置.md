# ArchLinux - 声音配置

## kde

全量安装直接用

最小安装，需要plasma-pa

## 无桌面

```bash
sudo usermod -a -G audio $USER
```

默认的alsa驱动可以直接用，但多个程序无法同时播放声音

混音需要用音频服务器

### 音频服务器Pipewire

```bash
paru -S pipewire pipewire-alsa
```

### 配置

#### 音量alsamixer

#### 默认设备wireplumber

```bash
paru -S wireplumber
wpctl status
wpctl set-default <设备ID>
```

## 音效

### EasyEffects

```bash
paru -S easyeffects qtractor lsp-plugins-lv2
```

下载导入预设 [https://raw.githubusercontent.com/JackHack96/EasyEffects-Presets/master/Advanced Auto Gain.json](https://raw.githubusercontent.com/JackHack96/EasyEffects-Presets/master/Advanced%20Auto%20Gain.json)
