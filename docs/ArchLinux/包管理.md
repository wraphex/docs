# ArchLinux - 包管理

## 查询命令对应的包

```bash
pacman -Ql | grep [command]
```

## 查询手动安装的包

```bash
pacman -Qe
```

## 查询显式安装的AUR包

```bash
pacman -Qm
```

## 查询依赖包

### 通用查询
（Depends On/Required By，单层）

```bash
pacman -Qi [package]
```

### 依赖树

```bash
pactree [package]
```

### 反向依赖树

```bash
pactree -r [package]
```

## 清理无用包

```bash
sudo pacman -Rns $(pacman -Qdtq)
```

## 安装指定版本AUR包

clone AUR包的git仓库到本地

编辑 `PKGBUILD`：

```bash
nano PKGBUILD
```

找到 `pkgver` 和 `pkgrel`，改为指定版本：

```
pkgver=xxx.xxx.xxx
pkgrel=x
```

重新生成校验和并编译安装：

```bash
updpkgsums
makepkg -si
```

> 编译安装的包可以在AUR包管理器（如`paru`）管理
