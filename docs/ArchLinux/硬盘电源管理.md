# ArchLinux - 硬盘电源管理

## hdparm

[https://wiki.archlinuxcn.org/wiki/Hdparm](https://wiki.archlinuxcn.org/wiki/Hdparm)

查看当前运行状态

```bash
sudo hdparm -C /dev/sda
```

## hd-idle

[https://github.com/adelolmo/hd-idle](https://github.com/adelolmo/hd-idle)

/etc/default/hd-idle

```
START_HD_IDLE=true
HD_IDLE_OPTS="-i 0 \
 -a /dev/disk/by-id/ata-WDC_WD3200BPVT-00ZEST0_WD-WXN1E61UUHR7 -c ata -i 300 \
 -l /var/log/hd-idle.log"
```

```bash
sudo systemctl enable --now hd-idle
```

2.5寸sata硬盘休眠（standby）功耗0.7w，唤醒2.3w

## usb硬盘盒

不支持主动电源管理，部分硬盘盒有内置电源管理，我手上的休眠功耗约0.8w，唤醒1.6w
