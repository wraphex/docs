# ArchLinux - 更换内核

以更换`linux-lts`为例

## 安装linux-lts

```bash
sudo pacman -S linux-lts
```

安装过程会hook触发mkinitcpio

## 更新Grub

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

执行后观察输出日志，确保看到了 `Found linux image: /boot/vmlinuz-linux-lts` 和 `Found initrd image: /boot/initramfs-linux-lts.img` 的字样。

## 重启并验证

### 选择内核

进入Grub选择带lts的linux启动

> 如果想永久默认启动 LTS，可以编辑 `/etc/default/grub`，修改 `GRUB_DEFAULT` 为对应菜单项的索引号或名称，然后再次运行 `grub-mkconfig`

### 验证当前内核

进入系统后，打开终端运行以下命令确认内核版本：

```
uname -r
```

- 如果输出包含 `lts`的版本号，则切换成功。

## 后续清理 (可选)

一旦你确认 `linux-lts` 运行稳定，并且不再需要默认的 `linux` 内核，你可以选择卸载它以节省空间。

**但在卸载前，请确保：**

1. 你已经用 LTS 内核成功启动过至少一次。
2. 你的所有硬件驱动（特别是显卡和网卡）在 LTS 内核下工作正常。

卸载命令：

```bash
sudo pacman -Rns linux linux-headers
```

卸载后，记得再次运行引导更新命令 `grub-mkconfig`，以免启动菜单中出现无效条目。
